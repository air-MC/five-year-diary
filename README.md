# 다섯 해의 기록 · Five Year Diary

하루 한 페이지, 같은 날짜의 다섯 해를 쓰는 5년 다이어리 웹앱입니다.
애플펜슬 손글씨와 키보드를 함께 쓰고, 종이처럼 넘기며, 인터넷 없이도 동작합니다.

## 설치 (홈 화면에 추가)
- **아이패드·아이폰 (Safari):** 앱 주소 열기 → 공유(□↑) → **홈 화면에 추가**
- **갤럭시 (Chrome/삼성 인터넷):** 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**

한 번 열고 나면 인터넷이 없어도 열립니다.

## 쓰는 법
- 앱은 항상 **오늘 날짜**로 열리고, 올해 칸에 `올해` 표시가 붙어요.
- ✏️ 펜: 애플펜슬로 쓰기 (굵기 · 색 3가지) · ⌫ 지우개: 닿은 획 지우기 · ⌨️ 키보드: 글자로 쓰기 · ↶ 실행취소
- 손가락으로 **좌우로 쓸면** 페이지가 넘어가요. 펜으로 쓰는 중에는 넘어가지 않아요.
- 펜슬이 없다면 ⚙ 설정 → **손가락으로도 쓰기** (이때 넘기기는 ‹ › 버튼)
- ⌂ 목록에서 월·날짜로 이동, 기록이 있는 날엔 점이 찍혀요.
- 2월 29일은 윤년인 해의 칸만 열려요.

## 백업 (중요)
기록은 **이 기기 안에만** 저장됩니다. 기기를 바꾸거나 앱을 지우기 전에 꼭 백업하세요.
- ⚙ 설정 → **백업 파일 만들기** → 공유 화면에서 **파일에 저장 → iCloud Drive**
- 복원: ⚙ 설정 → **백업에서 복원** → 백업 파일 선택 (같은 날짜는 더 최근 기록이 남아요)
- 7일 넘게 백업하지 않으면 화면 위에 알림이 떠요.

## 배포 (GitHub Pages)
저장소 Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
몇 분 뒤 `https://<계정>.github.io/five-year-diary/` 에서 열립니다.
파일을 바꾼 뒤에는 `sw.js`의 `VERSION`을 올려야 설치된 앱이 새 버전을 받아요.

## 개발
빌드 단계 없음 (순수 HTML/CSS/JS).
```bash
npm test          # 날짜·백업 로직 단위 테스트
npm run e2e       # Playwright 화면 흐름 테스트
npm run serve     # http://127.0.0.1:8080
node tools/make-icons.mjs   # 아이콘 다시 만들기
```
