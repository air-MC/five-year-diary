# 5년 다이어리 (디지털 판매용) — 설계

## 목적
태블릿 필기앱(굿노트·노타빌리티·삼성노트)에서 펜으로 쓰는 한국어 5년 다이어리 PDF.
판매·선물용. 아주 깔끔한 디자인.

## 목표 / 비목표 / 실패 조건
- 목표: 한 페이지 = 한 날짜 × 5년 칸, 탭 한 번에 이동하는 링크, 어느 해에 시작해도 쓸 수 있는 연도 빈칸형
- 비목표: 앱/서버, 키보드 입력, 인쇄용 버전(추후 가능)
- 실패 조건: 링크가 필기앱에서 안 먹힘, 글씨 쓸 공간이 좁음, 장식이 과해 "깔끔"하지 않음

## 접근 방식
- A. 하이퍼링크 PDF ← 선택 (판매·선물에 적합, 서버 불필요)
- B. 웹/모바일 앱 — 규모 몇 배, 선물로 건네기 애매해서 제외

## 정해진 것
- 한국어, 연도 "20__" 빈칸형(요일 없음), 2월 29일 포함 366일
- 구성: 표지 → 사용법 → 연간 인덱스(12개월) → 월별 날짜 목록 12쪽 → 날짜 366쪽
- 모든 날짜 페이지: 상단 날짜, 5칸(각 칸 "20__" + 줄), 오른쪽 월 탭(1~12월), 홈 링크

## 제 판단으로 정한 것 (수정 가능)
- 크기: 태블릿 세로 비율(아이패드 기준), 여백 넉넉히
- 디자인: 아이보리에 가까운 흰 바탕, 짙은 회색 글씨, 포인트 색 1개(차분한 세이지 그린), 얇은 점선/실선
- 폰트: Pretendard(무료 상업 이용 가능, SIL OFL) 임베드
- 표지 제목 가안: "다섯 해의 기록"
- 제작 방식: HTML/CSS로 만들고 Chromium으로 PDF 출력 (내부 링크 유지)
- 결과물: PDF 1개 + 미리보기 이미지 몇 장 (판매 페이지용)

## 빌더에게 남긴 것
- 줄 간격, 정확한 색상 값, 아이콘 세부 디자인

## 추가 (사용자 요청: 색 버전 + 스티커)
- 색 버전 3종: 세이지 그린 / 더스티 블루 / 로즈 베이지 — 구조 동일, 포인트 색만 다름 → PDF 3개
- 스티커 세트: 다이어리 톤에 맞는 단순 라인 아이콘
  - 날씨(맑음·흐림·비·눈·바람), 기분(5단계 얼굴), 별·하트·체크·꽃, 라벨 띠(오늘의 한 줄, 생일, 기념일, 여행 등)
  - 결과물: 투명 배경 PNG 개별 파일(굿노트 스티커 등록용) + 스티커 시트 PDF 1장 + 3색 각각
- 판매 패키지: zip 1개 = PDF 3종 + 스티커 + 사용 안내(txt)
