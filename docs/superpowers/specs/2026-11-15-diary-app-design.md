# 다섯 해의 기록 — 단독 다이어리 앱 (웹앱/PWA) 설계

## 목적
본인이 매일 쓰는 5년 다이어리. 종이처럼 넘기며, 펜(손글씨)과 키보드를 둘 다 쓴다.

## 목표 / 비목표 / 실패 조건
- 목표: 홈 화면 설치, 오프라인 동작, 책장 넘김, 펜+키보드, 오늘 페이지로 바로 열림, iCloud 백업/복원
- 비목표(1차): 기기 간 자동 동기화, 앱스토어 등록, 판매
- 실패 조건: 쓴 기록이 사라짐 / 펜 쓰다가 페이지가 넘어감 / 필기가 끊기거나 늦음

## 접근 방식
- A. 웹앱(PWA) ← 선택: 모든 기기, 여기서 바로 제작, 비용 0
- B. 아이패드 네이티브(Swift/PencilKit): 필기감 최고지만 맥+Xcode+$99/년, 여기서 빌드 불가
- C. 기존 PDF+굿노트: 단독 앱 아님

## 정해진 것 (사용자)
- 단독 앱, 넘기면서 쓰는 다이어리, 손글씨+키보드 모두, 한국어

## 제 판단 (수정 가능)
- 첫 실행 시 시작 연도 입력 → 5칸에 연도 자동 표시, 올해 칸 강조, 앱은 항상 오늘 날짜로 열림
- 칸마다 펜 레이어 + 글자 레이어 (같은 칸에 섞어 쓰기)
- 도구: 펜(굵기 2, 색 3) / 지우개 / 키보드 / 실행취소
- 애플펜슬로만 필기, 손가락은 넘기기 → 펜슬 오입력 방지. 펜슬 없는 기기는 "손가락으로 쓰기" 토글
- 넘김: 좌우 스와이프 시 종이 넘김 애니메이션, 월 탭·목록·오늘 버튼
- 디자인: PDF와 동일(Pretendard, 3색 테마 설정에서 변경)
- 저장: 기기 내(IndexedDB) 자동 저장 + 영구 저장 요청, 백업 파일 내보내기 → 공유 시트에서 iCloud Drive 저장, 복원
- 백업 알림: 7일 이상 백업 안 했으면 부드럽게 안내
- 스티커 붙이기: 2차
