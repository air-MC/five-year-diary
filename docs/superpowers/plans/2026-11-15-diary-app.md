# 다섯 해의 기록 앱 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 펜+키보드로 쓰고 종이처럼 넘기는 오프라인 5년 다이어리 웹앱(PWA)
**Architecture:** 빌드 단계 없는 정적 사이트(바닐라 JS ES 모듈). 순수 로직(dates/model/backup)은 DOM과 분리해 `node --test`로 검증, 화면 흐름은 Playwright 스크립트로 검증. 데이터는 IndexedDB, 앱 셸은 서비스 워커 캐시.
**Tech Stack:** HTML/CSS/JS(ES2022), IndexedDB, Pointer Events, Service Worker, Pretendard woff2, node:test, Playwright(사전 설치본)
**Spec:** docs/superpowers/specs/2026-11-15-diary-app-design.md

## Global Constraints
- 외부 런타임 의존성 0, 빌드 없음 (GitHub Pages 루트에서 그대로 서빙, 모든 경로 상대경로)
- 한국어 UI, Pretendard, 테마 sage #7C9A82 / blue #7A93AC / rose #C49A8F, 글씨 #3A3A3A, 바탕 #FCFBF8
- 칸 5개 = startYear … startYear+4, 앱은 오늘 날짜로 열림
- 펜 입력은 pointerType "pen"만(설정 fingerDraw=true면 touch도), 손가락 가로 스와이프 = 넘김
- 획 좌표는 칸 너비 기준 정규화 [x/w, y/w, pressure]
- 백업 JSON: `{app:"five-year-diary", version:1, exportedAt, settings, entries}`

### Task 1: dates.js — 날짜 계산
**Files:** Create `js/dates.js`, Test `tests/unit/dates.test.mjs`
**Produces:** `DAYS:number[12]`(2월=29), `isLeap(y):boolean`, `nextDay({m,d})`, `prevDay({m,d})`, `todayMD(now=new Date()):{m,d,y}`, `yearsForDay(startYear,{m,d}):{year,disabled}[]`, `key(y,m,d):"YYYY-MM-DD"`
- [ ] 테스트: isLeap(2028)=true, isLeap(2100)=false; nextDay({12,31})={1,1}; prevDay({1,1})={12,31}; nextDay({2,28})={2,29}; yearsForDay(2026,{2,29}) → 2028만 disabled:false; key(2026,1,5)="2026-01-05"
- [ ] 실패 확인 `node --test tests/unit` → 구현 → 통과 → 커밋

### Task 2: backup.js — 백업 형식·병합
**Files:** Create `js/backup.js`, Test `tests/unit/backup.test.mjs`
**Produces:** `makeBackup(settings, entries[]):object`, `parseBackup(text):{settings,entries}` (형식 불일치 시 throw Error("올바른 백업 파일이 아니에요")), `mergeEntries(local[], incoming[]):entry[]` (key 같으면 updatedAt 큰 쪽)
- entry 형태: `{key, text, strokes:[{c,w,p:[[x,y,pr]...]}], updatedAt}`
- [ ] 테스트: 라운드트립 동일; app 이름 틀림/JSON 아님 → throw; 병합 시 newer wins + 양쪽 고유 key 보존 → 구현 → 통과 → 커밋

### Task 3: store.js — IndexedDB
**Files:** Create `js/store.js`
**Produces:** `openStore():Promise<Store>`; Store: `get(key)`, `put(entry)`, `all()`, `getSettings()`, `setSettings(obj)`; 최초 open 시 `navigator.storage?.persist?.()`
- e2e(Task 5)로 검증. 커밋.

### Task 4: 화면 — index.html / styles.css / app.js / ink.js / flip.js
**Files:** Create `index.html`, `styles.css`, `js/app.js`, `js/ink.js`, `js/flip.js`
**Interfaces:** ink.js `createInk(canvas, {getTool, onChange, allowTouch})` → `{load(strokes), strokes(), undo(), resize()}`; 지우개 = 닿은 획 통째 삭제. flip.js `flip(container, direction, renderNext)` 3D 넘김(≈450ms, prefers-reduced-motion이면 즉시).
- 첫 실행: 시작 연도 입력 시트(기본=올해) → settings 저장
- 상단: 날짜, ‹ ›, [오늘], ⌂(월/날짜 목록 패널), ⚙(테마·손가락 쓰기·시작 연도·백업/복원)
- 도구바: 펜(얇게/굵게, 색 3) / 지우개 / 키보드 / 실행취소
- 칸: 연도 라벨 + 줄 배경 textarea + canvas 오버레이; 키보드 모드면 canvas pointer-events:none; 올해 칸 강조; 비활성 칸 회색
- 입력 300ms 디바운스 자동 저장; 마지막 백업 7일 경과 시 상단 안내 띠
- 백업: navigator.share({files})(가능 시, iOS 공유 시트 → 파일에 저장 → iCloud) 아니면 다운로드; 복원: file input → parseBackup → mergeEntries → 저장
- 데이터 속성 `data-testid` 부여: page-date, block-YYYY, text-YYYY, canvas-YYYY, next, prev, today, tool-pen, tool-keyboard
